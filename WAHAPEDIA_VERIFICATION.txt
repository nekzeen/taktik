================================================================================
                        DÉMARRAGE RAPIDE (5 ÉTAPES)
================================================================================

1. Installer la dépendance:
   composer require league/csv

2. Configurer les clés API dans .env:
   DEEPL_API_KEY=votre_clé_api_deepl
   # ou
   GOOGLE_TRANSLATE_API_KEY=votre_clé_api_google

3. Exécuter les migrations:
   php artisan migrate

4. Enregistrer la ressource Filament:
   diter app/Providers/Filament/AdminPanelProvider.php
   Ajouter: \App\Filament\Resources\TranslationResource::class,

5. Importer les données:
   php artisan wahapedia:import --force
